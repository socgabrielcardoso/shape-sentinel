# Project Profile

**Shape Sentinel** is a Java/OpenCV computer-vision laboratory for real-time geometric recognition and camera-based visual processing.

## What this project demonstrates
- Java 17 application structure
- OpenCV-based image processing
- Maven build automation
- JUnit test organization
- Real-time camera and contour-analysis concepts

## Portfolio signal
The project demonstrates practical Java maintenance and computer-vision fundamentals in a compact, testable application.

**Domain:** Computer Vision, Java  
**Stack:** Java 17, OpenCV, Maven, JUnit 5  
**Status:** Technical laboratory
