Detection pipeline

The webcam frame stays local. OpenCV prepares the image, isolates contours and sends the geometry to a small classifier.

01

Capture

Read frames from the selected camera.

02

Edges

Apply blur, Canny and morphological closing.

03

Contours

Approximate polygons and measure their geometry.

04

Classify

Label each supported shape with confidence.

Small scope. Real implementation.

No cloud service and no external processing. The app is a focused Java desktop exercise with native OpenCV bindings, unit tests and an automated build.
